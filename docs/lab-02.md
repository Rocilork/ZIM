# Лабораторная работа № 2. Ingestion и слой raw

Краткое описание того, что реализовано в ветке `lab-02`.

## Источник

Seoul Bike Sharing Demand (UCI Machine Learning Repository), файл `SeoulBikeData.csv`.

- Прямой HTTP-адрес: `https://archive.ics.uci.edu/ml/machine-learning-databases/00560/SeoulBikeData.csv`
- Объём: 604 166 байт, 8760 строк, 14 полей.
- SHA-256: `373339b71a8935d69e9af0abf26a70744632119862eeb3919efb389a7b749c60`.
- Неизменяемая копия для ручного fallback: `data/source/SeoulBikeData.csv` (байт в байт совпадает с ответом HTTP).

## Что делает DAG `ingest_raw`

1. `wait_for_primary_source` — `HttpSensor` проверяет доступность основного файла
   (соединение `source_http_conn`, метод `HEAD`, `poke_interval=60`, `timeout=600`).
2. `load_to_raw` — `PythonOperator`, который выполняется после сенсора:
   - формирует ключ `s3://raw/<dataset_slug>/ingested_on={{ ds }}/<имя_файла>`;
   - проверяет через S3 API, что бакет `raw` существует; если бакета нет, задача завершается
     ошибкой с понятным сообщением и не создаёт бакет самостоятельно;
   - если объект по этому ключу уже есть, задача завершается успешно без загрузки и без изменения
     существующего объекта;
   - иначе скачивает файл по HTTP и загружает байты через `S3Hook.load_bytes` с `replace=False`.

Логическая дата `{{ ds }}` берётся из контекста запуска Airflow, а не из текущей даты.

## Проверка чтения через DuckDB

```bash
uv run --env-file .env python scripts/read_raw.py --path \
  "s3://raw/seoul_bike/ingested_on=<логическая_дата>/SeoulBikeData.csv"
```

Особенность источника: заголовок файла опубликован в кодировке cp1252 (в именах температурных
полей стоит байт `0xB0`, знак градуса), а данные содержат только ASCII. Поэтому в
`src/analysis/read_raw.py` для CSV заголовок пропускается, а имена столбцов задаются явно. Это
позволяет читать объект из `raw` без изменений и работает как на закреплённом в проекте DuckDB
1.1.3, так и на более новых версиях.

## Идемпотентность

Повторный запуск DAG за ту же логическую дату не создаёт дубликатов: существующий raw-объект
обнаруживается через `check_for_key` и не перезаписывается.
